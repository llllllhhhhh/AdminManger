# 学徒行内容装修后台

与 `xuetuxing` uni-app 小程序内容对应的 Vue 3 管理后台，基于 Vite 构建。

## 运行

```bash
npm install
npm run dev
```

默认访问地址：`http://localhost:5178`

生产构建：

```bash
npm run build
```

构建结果位于 `dist`，可部署到 Nginx、宝塔面板、Vercel 或其他静态托管服务。

## 已实现功能

- 数据总览与运营待办
- 三栏可视化页面装修器
- 手机端实时效果预览
- 页面组件增删、隐藏和上下排序
- 标题、副标题、图片、按钮、颜色、进度与宫格入口编辑
- 自定义页面新建、复制、发布和删除
- 品牌 Logo、标语与全局主题色装修
- 积分邀请及泰山游兑换规则配置与实时模拟
- 旅行路线新增、编辑、上下架和库存维护
- 积分兑换、人工定制订单审核
- 配置本地保存、恢复默认、JSON 导入和导出

## 数据说明

当前版本使用浏览器 `localStorage` 保存装修草稿，适合作为可交互原型与前端开发基础。点击“发布到小程序”会生成已发布配置快照。

接入生产环境时，可将 `App.vue` 中的 `save`、`publish`、`importConfig` 方法替换为后端 API，请求返回的数据结构保持与 `src/data/defaultConfig.js` 一致。小程序端启动时读取发布配置，即可实现真正的跨端实时装修。
